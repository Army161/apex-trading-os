Open Code itself is an open-source coding agent from the team at Anomaly. It runs in the terminal as a desktop app and inside your IDE and it isn't tied to one AI company. You can plug in claude, GPT, Gemini, open models, even local models running on your own machine. That flexibility is a big reason so many developers moved to it. The one thing people kept asking for was browser control. Clawed users already had Claude in Chrome where the agent clicks around inside your actual browser. Open code users had nothing official. Browse is the official version and it behaves a lot like claude in Chrome. The difference is it's open source, MIT licensed and works with whatever model you pick. It's made of two pieces. An MCP server that your agent talks to and an extension that lives inside your browser. Between them, there's a small relay running on your own computer. So, the flow goes like this. Your agent sends a command to the MCP server. The server passes it to the local relay. The relay sends it over a websocket to the extension. and the extension runs it in your browser using Chrome's built-in debugger. The agent actually writes playwright code to drive the page so it can click, type, fill forms, take screenshots, record the screen, and capture network traffic. Agent tabs don't pop up in your face while you work. They open in the background, grouped together at the start of your tab strip, and the group stays collapsed unless you click into it. The agent can't switch you over to its tab or pull a window to the front. If a site opens a popup, it joins the agents group, too. And tabs nobody touches for 10 minutes close by themselves. You can change most of this in the extension settings. For example, you can give agents their own separate window, give each agent session its own group, or turn off the grouping completely. You can also lend the agent a tab you already have open. You click the extension button on that tab and the badge says on. While the agent is working, it says run and when it needs you, it says wait. Clicking the button again takes the tab back right away, even in the middle of a script. Handoffs are the login part I mentioned. When the agent reaches a login, a 2FA prompt, or a payment step, it shows a small card on the page with the site's address. You do that part yourself, then click continue, and the agent picks up from there. Only a real click from you finishes the handoff, so a web page can't fake it and push the agent forward. Recordings are clean, too. When the agent records a tab, nothing from browse shows up in the video. No cursor, no labels, no card. If you want a cursor for a demo, you can ask for a ghost cursor. There's also a flight recorder mode that keeps the last minute of video, so when something breaks, you can save exactly what happened. Security got a lot of attention here, which makes sense since it's driving the browser where you're signed into everything. They assume any page the agent reads could try to steer it.
